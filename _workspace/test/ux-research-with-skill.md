# 전환율 분석 & A/B 테스트: 이커머스 앱 장바구니-결제 전환율 개선

## 요약 (Executive Summary)

- 이커머스 앱의 장바구니-결제 전환율이 30%로, 업계 평균(약 45~55%) 대비 현저히 낮은 수준이다.
- 퍼널 분석 결과, 이탈이 집중되는 3대 구간은 (1) 결제 수단 입력 단계, (2) 배송 정보 입력 단계, (3) 최종 결제 확인 단계로 추정된다.
- 결제 프로세스 간소화(단계 축소)를 핵심 가설로 설정하고, A/B 테스트를 통해 검증한다.
- 테스트 성공 시, 전환율을 30%에서 최소 36%(상대적 20% 개선)로 끌어올리는 것을 목표로 한다.
- 추가로 정성 리서치(사용자 인터뷰)를 병행하여 이탈 원인의 심층 이해를 확보한다.

## 방법론

| 항목 | 내용 |
|------|------|
| **사용한 방법** | 퍼널 로그 분석(정량), A/B 테스트(정량), 심층 인터뷰(정성), 사용성 테스트(정성) |
| **참여자 수/특성** | 로그 분석: 최근 30일 장바구니 이용 전체 사용자 / 인터뷰: 최근 장바구니 이탈 사용자 8~12명 / A/B 테스트: 그룹당 약 4,000명 |
| **기간** | 리서치 계획 1주 + 정성 리서치 2주 + A/B 테스트 3주 + 분석 1주 = 총 7주 |

## 1단계: 리서치 계획 수립

### 리서치 질문

1. "왜 사용자가 장바구니에 상품을 담고도 결제를 완료하지 않는가?"
2. "결제 프로세스의 어느 단계에서 가장 많은 이탈이 발생하는가?"
3. "결제 프로세스를 간소화하면 전환율이 유의미하게 증가하는가?"

### 가설 수립

| # | 가설 | 검증 방법 |
|---|------|-----------|
| H1 | 결제 단계가 4단계 이상으로 과도하여 피로감이 이탈의 주 원인이다 | 퍼널 로그 분석 + 사용자 인터뷰 |
| H2 | 결제 프로세스를 멀티스텝(4단계)에서 싱글페이지(1단계)로 축소하면 전환율이 20% 이상 상대적으로 증가할 것이다 | A/B 테스트 |
| H3 | 예상치 못한 추가 비용(배송비, 수수료) 노출이 최종 확인 단계에서 이탈을 유발한다 | 로그 분석 + 인터뷰 |
| H4 | 게스트 결제 옵션 부재가 신규 사용자의 이탈을 유발한다 | 세그먼트별 전환율 비교 |

## A/B 테스트 설계

### 테스트 1: 결제 프로세스 간소화

#### 가설
"현재 4단계 멀티스텝 결제 프로세스(대조군 A)를 싱글페이지 원스텝 결제(변형 B)로 변경하면, 장바구니-결제 전환율이 상대적으로 20% 이상 증가할 것이다."

#### 변수 정의

| 변수 유형 | 항목 | 설명 |
|-----------|------|------|
| **독립변수** | 결제 프로세스 구조 | A: 4단계 멀티스텝 / B: 1페이지 아코디언 방식 |
| **종속변수** | 장바구니-결제 전환율 | 결제 완료 수 / 장바구니 진입 수 (%) |
| **종속변수 (보조)** | 결제 완료 소요 시간 | 장바구니 CTA 클릭~결제 완료 (초) |
| **종속변수 (보조)** | 결제 오류 발생률 | 결제 시도 중 오류 발생 비율 |
| **통제변수** | 트래픽 소스 | 동일 비율로 분배 (랜덤 배정) |
| **통제변수** | 디바이스 | 모바일/데스크톱 비율 동일하게 층화 |
| **통제변수** | 시간대 | 동일 기간 동시 실행 |
| **통제변수** | 상품 카테고리 | 제한 없음 (전체 카테고리) |

#### 대조군 (A) vs 변형 (B) 상세

**대조군 A - 현재 4단계 프로세스:**
1. 배송 정보 입력 페이지
2. 결제 수단 선택/입력 페이지
3. 주문 요약/확인 페이지
4. 결제 처리/완료 페이지

**변형 B - 싱글페이지 원스텝 결제:**
- 하나의 페이지에 아코디언(접이식) 섹션으로 배송 정보, 결제 수단, 주문 요약을 배치
- 배송비 포함 총 결제 금액을 페이지 상단에 고정 표시
- 간편결제(카카오페이, 네이버페이, 토스) 버튼을 최상단에 배치
- 최근 배송지/결제 수단 자동 선택 (재구매 사용자)

#### 표본 크기 계산

| 파라미터 | 값 | 근거 |
|----------|-----|------|
| 기저 전환율 (baseline) | 30% | 현재 장바구니-결제 전환율 |
| 최소 감지 효과 (MDE) | 상대적 20% (절대적 6%p, 즉 30% -> 36%) | 비즈니스적으로 의미 있는 최소 개선폭 |
| 유의 수준 (alpha) | 0.05 (양측 검정) | 업계 표준 |
| 검정력 (1-beta) | 0.80 | 업계 표준 |
| **그룹당 필요 표본 크기** | **약 4,000명** | 비율 비교 z-검정 기준 산출 |
| **총 필요 표본 크기** | **약 8,000명** | 두 그룹 합산 |

> 표본 크기 산출 근거: 두 비율(p1=0.30, p2=0.36)의 차이를 검정하기 위한 표본 크기 공식 적용.
> n = (Z_alpha/2 + Z_beta)^2 * (p1(1-p1) + p2(1-p2)) / (p2 - p1)^2
> n = (1.96 + 0.84)^2 * (0.30*0.70 + 0.36*0.64) / (0.06)^2
> n = 7.84 * (0.21 + 0.2304) / 0.0036
> n = 7.84 * 0.4404 / 0.0036 = approx. 959 (이론값)
> 실무 보정: 이탈/무효 트래픽 감안하여 그룹당 4,000명으로 설정

#### 테스트 실행 계획

| 항목 | 내용 |
|------|------|
| 트래픽 배분 | 50:50 랜덤 배정 |
| 실행 기간 | 최소 3주 (참신성 효과 배제 위해 2주 + 안정화 1주) |
| 일일 예상 장바구니 진입 | 약 500~600명 기준, 약 14~16일 소요 |
| 조기 종료 조건 | 금지 - 사전 정의된 표본 크기 도달 시에만 분석 |
| 세그먼트 분석 | 디바이스별(모바일/데스크톱), 신규/기존 사용자별, 주문 금액대별 |

#### 흔한 함정 회피 체크리스트

- [x] **조기 종료 금지**: 표본 크기 8,000명 도달 전 결과 판정하지 않음
- [x] **참신성 효과 배제**: 최소 3주 실행
- [x] **심슨의 역설 대비**: 모바일/데스크톱, 신규/기존 사용자 세그먼트별 결과 분리 분석
- [x] **다중 비교 보정**: 테스트 1개이므로 해당 없음 (추후 테스트 추가 시 Bonferroni 보정)

## A/B 테스트 예상 결과 (결과 분석 프레임워크)

### A/B 테스트 결과: 결제 프로세스 간소화

#### 개요
| 항목 | 대조군 (A) - 4단계 멀티스텝 | 변형 (B) - 싱글페이지 원스텝 |
|------|---------------------------|----------------------------|
| 표본 크기 | 4,000 | 4,000 |
| 전환율 | 30.0% | (목표) 36.0% |
| 신뢰 구간 (95%) | [28.6%, 31.4%] | [34.5%, 37.5%] |

#### 통계 검정 (목표 달성 시)
- **p-value**: < 0.001 (예상)
- **상대 효과 크기**: +20.0%
- **절대 효과 크기**: +6.0%p
- **통계적 유의성**: 유의함 (p < 0.05)

#### 판정 (목표 달성 시)
- **승자**: B (싱글페이지 원스텝 결제)
- **권고**: 전체 트래픽에 변형 B를 적용하되, 2주간 모니터링 후 완전 전환
