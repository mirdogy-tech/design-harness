# UX 리서치 & A/B 테스트

사용자 중심 리서치를 수행하고, A/B 테스트로 디자인 가설을 검증한다.

## 리서치 워크플로우

### 1단계: 리서치 계획 수립
1. 리서치 질문 정의 — "왜 사용자가 X에서 이탈하는가?" 형태의 구체적 질문
2. 가설 수립 — 검증 가능한 형태로 ("X를 Y로 변경하면 전환율이 Z% 증가할 것이다")
3. 방법론 선택 — 아래 매트릭스 참조
4. 성공 지표(KPI) 정의

### 방법론 선택 매트릭스

| 목적 | 정성적 방법 | 정량적 방법 |
|------|-----------|-----------|
| 탐색 (왜?) | 심층 인터뷰, 맥락적 조사 | 설문 (개방형), 로그 분석 |
| 평가 (얼마나?) | 사용성 테스트, 카드 소팅 | A/B 테스트, 설문 (폐쇄형) |
| 생성 (무엇을?) | 참여적 디자인, 브레인스토밍 | 트리 테스트, 퍼스트 클릭 |

### 2단계: 리서치 실행

#### 사용자 인터뷰 분석
- 인터뷰 데이터에서 주제(Theme) 추출 — 친화도법(Affinity Mapping) 활용
- 주제별 빈도, 감성(긍정/부정/중립), 인용문 정리
- 인사이트 도출: 패턴 → 인사이트 → 디자인 함의(Implication)

#### 페르소나 생성
```markdown
## 페르소나: {이름}
- **인구통계**: 나이, 직업, 기술 수준
- **목표**: 달성하려는 것
- **좌절점**: 현재 겪는 어려움
- **행동 패턴**: 제품 사용 방식
- **핵심 니즈**: 가장 중요하게 여기는 것
- **인용문**: 대표 발언
```

#### 사용자 여정 맵
단계별로 작성: 인식 → 탐색 → 결정 → 사용 → 재방문
각 단계에 **행동**, **생각**, **감정**(😊😐😟), **터치포인트**, **기회 영역** 기록.

#### 사용성 평가
- 태스크 시나리오 작성 (현실적이고 구체적인 시나리오)
- 평가 지표: 완료율, 오류율, 시간, SUS 점수, 만족도
- 심각도 등급: Critical / Major / Minor / Cosmetic

### 3단계: 인사이트 종합
- 발견 사항을 **영향도(Impact) × 확신도(Confidence)** 매트릭스로 정리
- 각 인사이트에 디자인 권고안 연결
- 우선순위: 높은 영향도 + 높은 확신도 → 즉시 반영

## A/B 테스트

### 테스트 설계
1. **가설**: "변형 B가 대조군 A보다 [지표]에서 [방향]일 것이다"
2. **독립변수**: 변경하는 요소 (버튼 색상, 레이아웃, 문구 등)
3. **종속변수**: 측정하는 지표 (전환율, 클릭률, 체류 시간 등)
4. **통제변수**: 고정하는 조건 (트래픽 소스, 시간대, 디바이스 등)

### 표본 크기 계산
필요 정보:
- 기저 전환율 (baseline conversion rate)
- 최소 감지 효과 (MDE, Minimum Detectable Effect)
- 유의 수준 (α, 보통 0.05)
- 검정력 (1-β, 보통 0.80)

### 결과 분석 프레임워크

```markdown
## A/B 테스트 결과: {테스트명}

### 개요
| 항목 | 대조군 (A) | 변형 (B) |
|------|-----------|----------|
| 표본 크기 | n | n |
| 전환율 | x% | y% |
| 신뢰 구간 (95%) | [a%, b%] | [c%, d%] |

### 통계 검정
- p-value: {값}
- 상대 효과 크기: {값}%
- 통계적 유의성: 유의함 / 유의하지 않음

### 판정
- **승자**: {A 또는 B 또는 판정 불가}
- **권고**: {구체적 행동 권고}
- **주의사항**: {표본 크기 한계, 세그먼트별 차이 등}
```

### 흔한 함정 회피
- **조기 종료 금지**: 미리 정한 표본 크기에 도달할 때까지 결과를 판정하지 않는다
- **다중 비교 보정**: 3개 이상 변형 시 Bonferroni 보정 적용
- **참신성 효과(Novelty Effect)**: 최소 2주 이상 실행하여 참신성 효과를 배제한다
- **심슨의 역설**: 전체 결과와 세그먼트별 결과가 다를 수 있으므로 세그먼트 분석 병행

## 산출물 형식

모든 리서치 산출물은 다음 구조를 따른다:

```markdown
# {리서치 유형}: {주제}

## 요약 (Executive Summary)
- 핵심 발견 3~5개

## 방법론
- 사용한 방법, 참여자 수/특성, 기간

## 상세 결과
(유형별 상세 내용)

## 인사이트 & 권고안
| # | 인사이트 | 영향도 | 확신도 | 권고안 |
|---|---------|--------|--------|--------|
| 1 | ... | 높음/중간/낮음 | 높음/중간/낮음 | ... |

## 다음 단계
- 추가 리서치 필요 사항
- 디자인 반영 우선순위
```
